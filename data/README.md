# Dataset

The Power BI analysis uses a country-level COVID-19 vaccination dataset covering the 2021–2022 analysis period.

## Data Used in the Project

The dataset contains vaccination-related fields used to investigate:

- people vaccinated
- people fully vaccinated
- total vaccinations
- daily vaccinations
- vaccinations per hundred
- daily vaccinations per million
- country-level vaccination trends
- vaccination data sources

## Data Preparation

According to the project report, the dataset was loaded into Power BI Desktop and cleaned before analysis. The documented workflow included checking/removing missing values and duplicates and replacing null values with zero.

## Data Quality Note

Replacing missing values with zero was part of the original project methodology. However, a missing observation does not necessarily represent a true value of zero. This treatment can therefore affect aggregations and should be considered a limitation of the original analysis.
