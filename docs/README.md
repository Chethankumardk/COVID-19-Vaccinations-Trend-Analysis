# Project Documentation

This folder contains supporting documentation for the COVID-19 Vaccinations Trend Analysis project.

## Included File

### `covid19_vaccination_trend_analysis_report.pdf`

The report documents:

- project aim and problem statement
- Power BI analysis methodology
- data preprocessing approach
- vaccination trend visualizations
- country-level analysis
- observations and recommendations
- project conclusion

## Publication Note

The report is retained as supporting documentation for the original project.

The repository README provides additional context about analytical limitations identified during the portfolio review, including the treatment of missing values and the aggregation of cumulative vaccination measures.
