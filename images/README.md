# Power BI Analysis Visuals

This folder contains selected visuals from the COVID-19 Vaccinations Trend Analysis project.

## Included Visuals

### Daily Vaccination Trend

![Daily Vaccination Trend](covid_daily_vaccination_trend.png)

Shows the vaccination activity over time during the 2021–2022 analysis period.

### Fully Vaccinated by Country

![Fully Vaccinated by Country](covid_fully_vaccinated_by_country.png)

Shows the country-level comparison presented in the original Power BI analysis.

> **Note:** The original project used summed cumulative vaccination fields in some country-level visuals. Therefore, these values should be interpreted as outputs of the original exploratory Power BI analysis rather than as latest-date vaccination totals.
